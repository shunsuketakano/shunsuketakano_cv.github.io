## Overview

This HTML-based game allows players to learn how to randomise a honeycomb graph through the “diagonal flip” operation. This operation is described in [Dresselhaus *et al.*, Phys. Rev. B **112**, 064202 (2025)]. The score increases with the diversity of generated polygons and is calculated using Shannon entropy.
